## 再開に要る事実

### 実測で分かった落とし穴

**Oasis Sapphire**
- **コンストラクタに `string` を渡すと配備が status 0 で失敗する。**
  `bytes32`・mapping・引数なしは成功。文字列の返り値も `invalid code` で落ちた。
  → 表示名はチェーンに置かず画面側で持つ。公式ドキュメントに記載を見つけられなかった
- **履歴の照会は100ブロックまで。** `max allowed of rounds in logs query is: 100`。
  秘匿チェーンでは過去を自由に走査できない
- `forge script` は成功しても待機側がタイムアウトすることがある。
  `broadcast/Deploy.s.sol/23295/*.json` から配備アドレスを読める

**EDINET**
- **PDF本体はAPIキー不要**で取れる
  `https://disclosure2dl.edinet-fsa.go.jp/searchdocument/pdf/<docID>.pdf`
- **書類一覧(documents.json)はキーが要る**。無料登録。1Password の "EDINET API"
- **「節度のある利用」が求められる。** 1.2秒間隔にしてある。
  負荷が高いと運用側が手動でキーを止めることがある
- **書類種別では不動産STを絞れない。** 「内国信託受益証券等」の半分が
  株価指数連動の仕組債。本文で再分類が要る

**PDFの表**
- 座標方式(pdftotext -bbox-layout)は**行ピッチ11.7ptの雛形で破綻する**。
  折り返しと別行がΔyで区別できない
- **罫線方式(pdfplumber)が正解。** 再現率91.1%
- 取りこぼしは2つの型 ─ 入れ子の見出しの下、括弧が改行をまたぐもの

**zsh**
- `for a in "x y z"; do cmd $a` は単語分割されない。`${=a}` か1行1コマンド
- `print "--- ... ---"` は `-` をオプションと解釈する。`print -r --` を使う
